# Game feel / juice — отклик, эскалация, звук

Философия (Balatro): juice — не украшение, а половина продукта. Но juice ≠ «побольше анимаций»:
это **соразмерный отклик на событие**. Продуктовое требование — PRD §5.9.4; текущий план — BACKLOG R15;
замеренная база — [аудит 2026-08-09](../../../docs/audits/2026-08-09-roguelite-feel-audit.md).

## Правило 0 — лестница эскалации

Слои отклика пропорциональны масштабу события. Одинаковый отклик на всё == отсутствие отклика.

| Масштаб | Примеры | Слои |
|---|---|---|
| Обычное действие | покупка, reroll, взять награду | exit/enter-анимация + вспышка направления |
| Редкое событие | апгрейд редкости, босс-этап, апгрейд качества | + пульс рамки / синг / питч-слой звука |
| Кульминация | этап пройден, Aegis взят, смерть забега, победа сезона | полная секвенция (перекрытие, построчный счёт выплат, опц. shake) |

Перед добавлением эффекта назови масштаб события. Shake — **только** кульминации; вешать его на
частые события запрещено (инфляция обнуляет лестницу).

## Motion-бюджет (из design-language.md — читать при любой правке)

- Вход элемента 0.3–0.5s; стаггер 0.06–0.12s, **тем короче, чем плотнее раскладка** (камп: 45ms).
  Считай не один пак, а весь забег: 10 паков × 1.58s = 16 секунд движения.
- Бесконечные анимации — только арт/статус (`card-foil`, `live-pulse`). В игровом цикле их нет.
- **Вспышка, а не состояние:** изменение показывается `--win`/`--loss` и возвращается к нейтрали
  (`--motion-flash`). Цвет насовсем — потеря сигнала.
- Только `transform`/`opacity` в кейфреймах игрового цикла — не дёргать layout.
- `prefers-reduced-motion` обязателен — глобальное правило по `*` в `design/base.css` уже гасит всё;
  не обходи его локальными стилями.

## Запреты из реальных шишек (каждый стоил часов)

1. **Числа решений не набегают.** `useCountUp` на золоте показал 6 при настоящих 7: rAF тормозится в
   фоновой вкладке (R14.4). Золото, Run power, цены — всегда точные; анимируй вспышку/появление,
   НЕ значение.
2. **Keyframes — в глобальном CSS** (`design/base.css` или feature-css без модуля). CSS Modules
   скоупят имена `@keyframes`: определение в одном файле + ссылка из `*.module.css` молча не играет.
3. **Проверяй `document.getAnimations()`, не `getComputedStyle`** — второй показывает
   `running` у неработающей анимации. Замер «до/после» обязателен (скилл-чек: анимация видна в
   `getAnimations()` с ожидаемым duration/delay).
4. **Ключ раздачи ≠ ключ перерисовки.** Раздача (`Dealt`) переигрывается только когда реально
   пришли новые карты: реролл-ключ по `marketSerial`, но НЕ по нему для неизменных блоков —
   перемонтирование неизменных карточек мигает (R14.9). Проверка: `currentTime` анимации монотонно
   растёт через реролл.
5. **Exit-анимация — в UI-state, не в движке.** «Уходящий» оффер держи локально до
   `onAnimationEnd`; `consumed`-офферы отфильтрованы движком, и протаскивать их обратно ради
   косметики нельзя (довод R13.3 про SOLD-заглушку).
6. **Секвенции — presentation shortcut.** Все числа берутся из уже посчитанного
   (`prizeBreakdown`, снапшот турнира); скип по клику обязателен; resume посреди секвенции не
   дублирует эффекты (идемпотентность `finishTournament`). `Rng`-поток и golden не двигаются.

## Звук (когда дойдёт слой R15.5)

- WebAudio-менеджер один на приложение; unlock на первом жесте (autoplay policy) — до жеста тишина
  и ноль ошибок в консоли.
- Master-тумблер в Settings, persist через `state/persist.ts`; в TMA уважать мут клиента.
- Набор маленький и семантичный; эскалация — питчем и слоями (deal ×N с растущим питчем — приём
  Balatro), не громкостью. Ассеты — `web/public/sfx/`, суммарно десятки KB, не мегабайты.
- Игра полноценна в тишине: звук усиливает, но не несёт единственный сигнал (a11y).

## Чек перед «готово»

- [ ] Масштаб события назван, слои соответствуют лестнице.
- [ ] `getAnimations()` показывает эффект с ожидаемым duration/delay (и его отсутствие при
      reduced-motion).
- [ ] Числа решений точные в конце любой анимации; фоновая вкладка не искажает.
- [ ] `Skip`/`Show result`/resume не оставляют осиротевших анимаций и не дублируют эффекты.
- [ ] Классика не тронута: golden/e2e зелёные, `Rng`-поток на месте.
