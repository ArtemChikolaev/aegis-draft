# План до сложной реализации

Перед изменениями сообщи ожидаемый результат, основные шаги, что переиспользуешь и как проверишь. Обычно достаточно 3–5 предложений; не составляй обязательный список файлов для очевидной задачи.

- Если решение обратимо и входит в поручение, выбери разумный вариант, обозначь существенное допущение и продолжай. «Делай как считаешь нужным» уже задаёт автономию.
- Вопрос нужен, когда ответ меняет требуемое поведение, затраты или необратимое действие и не следует из переписки. Задай конкретный вопрос; независимую подготовку продолжай.
- При расхождении с PRD объясни его. Явное новое поручение пользователя может менять старое решение; одно наличие расхождения не требует повторного разрешения.
- Найденную смежную проблему зафиксируй отдельно. Не включай большую непорученную реализацию в текущую задачу.
- Согласование плана не заменяет ограничения среды. Если инструмент блокирует действие, точно сообщи действие и причину; не придумывай требование согласования от скилла.

Выход: короткий рабочий план и только действительно открытые вопросы. Нет обязательного «Ок? Идём?».
