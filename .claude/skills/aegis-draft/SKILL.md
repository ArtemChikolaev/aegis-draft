# Работа в aegis-draft

1. Прочитай [CLAUDE.md](../../../CLAUDE.md), доступный также через AGENTS.md, и [маршрутизацию](../../../docs/ai/INDEX.md). Пользовательские указания имеют приоритет над процедурами скиллов в рамках правил среды.
2. По задаче открой только нужные профильные SKILL.md; загружай references по необходимости. Не читай весь каталог заранее.
3. Перед новым кодом найди точки расширения. Для сложной работы кратко сообщи план и продолжай в порученных границах. Не превращай план в обязательное согласование.
4. Правь канонические файлы, сохраняй чужие изменения. Проверки выбирай по изменённой области; до завершения используй [self-review-checklist](../self-review-checklist/SKILL.md).
5. При запросе анализа отделяй факты, ограничения проверки и предложения. Не реализуй дизайн-предложения без поручения на реализацию.

Этот router общий для Claude Code и Codex. Доступные инструменты определяются текущей средой; имена моделей не требуют копий инструкций. Пути команд считаются от корня репозитория, если не указано иначе.
