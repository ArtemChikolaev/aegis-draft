# Спрайты и тайлы Liberated Pixel Cup (LPC) в режиме Аркада

Файлы в этой папке — часть открытых наборов LPC, используются как временный арт-слой (BACKLOG T13.13).
Лицензии: **CC-BY-SA 3.0**, **GPL 3.0** (по выбору), для части работ также **OGA-BY 3.0**. Атрибуция обязательна и показывается на экране режима.

## `char/` — [LPC] Medieval Fantasy Character Sprites (+ expansion pack)
- Автор: **Johannes Sjölund (wulax)**; базовые тела мужчины — авторы LPC base assets (см. ниже).
- Источник: https://opengameart.org/content/lpc-medieval-fantasy-character-sprites
- Лицензии: CC-BY-SA 3.0 / GPL 3.0 / OGA-BY 3.0. Автор отказался от DRM-оговорки CC при указании авторства.
- Оригинальный README — `README_lpc_entry.txt`.

## `monsters/`, `tiles/` — Liberated Pixel Cup Base Assets (sprites & map tiles)
- Авторы: **Lanea Zimmerman (Sharm)**, **Stephen Challener (Redshrike)**, **Charles Sanchez (CharlesGabriel)**, **Manuel Riecke (MrBeast)**, **Daniel Armstrong (HughSpectrum)** и другие — полный список в `CREDITS_lpc_base_assets.txt`.
- Источник: https://opengameart.org/content/liberated-pixel-cup-lpc-base-assets-sprites-map-tiles
- Лицензии: CC-BY-SA 3.0 / GPL 3.0.

Наши изменения: файлы не редактировались; в игре слои собираются в композит и подкрашиваются на лету (оттенок «расы»/героя). Производная работа (композиты на экране) распространяется на тех же условиях CC-BY-SA 3.0.
